### 2c. Scope question (PRESENT TO USER — wait for answer)

> **Stage 2: Scope Definition**
>
> I've mapped the full interface for `<ServiceName>`. Complete verb catalog:
> _(list all verbs from 2a)_
>
> For the OBS, we cover only the operations your use case requires. Please answer:
>
> 1. **Which nouns** are in scope? _(select from list, or "all")_
> 2. **Which verbs** are in scope? _(select from list, or "all")_
> 3. **Render scope** — should the OBS include:
>    - [ ] 3D viewport render primitive
>    - [ ] GUI panel refresh primitive
>    - [ ] Both
>    - [ ] Neither (data-only OBS)
> 4. **Gaps** — any operations you need that the current interface doesn't support?
> 5. **Client context** — is this OBS for a headless/automated client, or a GUI-active context?
>    (Headless clients cannot rely on indirect auto-propagation via workflow controllers.)

Once the user answers, record the scope decisions and proceed.
